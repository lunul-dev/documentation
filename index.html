# Introduction to Lunul Foundation

Lunul Foundation (LF) is an institutional-grade, private EVM Layer-1 blockchain protocol designed specifically as a corporate privacy-as-a-service provider. Operating as a secure VPN for your wallet, Lunul empowers banks, corporations, DAOs, and high-net-worth entities with lightning-fast transaction execution paired with absolute financial confidentiality.

By combining full Ethereum Virtual Machine (EVM) compatibility with zero-knowledge UTXO (ZK-UTXO) circuits and Pedersen commitments, developers can deploy standard Solidity contracts that execute under complete cryptographic shielding.

1. EVM Compatibility & ZK-UTXO Privacy Circuits

Legacy privacy chains often force developers to learn custom virtual machines or exotic programming languages. Lunul bridges this gap by offering native EVM runtime support combined with zero-knowledge circuits.

Zero-Knowledge State Proofs

Transactions verify mathematical validity without revealing sender balances, recipient addresses, or transaction graph connections to public observers or MEV bots.

Seamless Solidity Integration

Deploy standard smart contracts written in Solidity with zero code modifications, instantly enabling confidential asset transfers and private DeFi liquidity.

2. Wallet VPN & Enterprise Anonymity

Lunul acts as a secure cryptographic tunnel—a VPN for your wallet. For corporations managing treasuries and banks executing institutional settlements, financial surveillance creates severe security risks.

By leveraging cryptographic blinding factors and Pedersen commitments, Lunul shields all transaction payloads. External blockchain explorers see only verified zero-knowledge proofs, effectively anonymizing the underlying business operations while maintaining strict regulatory compliance capability.

4. Shielded Solidity Smart Contract Environment

Developers can deploy secure, confidential smart contracts using standard EVM bytecode. All state variables are protected under zero-knowledge encryption primitives, ensuring complete isolation from data scrapers.

ShieldedVault.sol • Solidity 0.8.24
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import "@lunul/zk-evm/contracts/ShieldedState.sol";

contract InstitutionalVault is ShieldedState {
    mapping(bytes32 => uint256) private shieldedBalances;

    function depositEncrypted(bytes32 commitment) external payable {
        require(msg.value > 0, "Zero deposit");
        _verifyPedersenCommitment(commitment, msg.value);
        shieldedBalances[commitment] += msg.value;
    }
}
