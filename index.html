GETTING STARTED / INTRODUCTION

Introduction to Lunul Foundation

Lunul Foundation (LF) is a high-throughput, horizontally scalable layer-1 blockchain protocol engineered for institutional-grade decentralized finance, ultra-low latency execution, and secure cross-chain composability. By combining deterministic finality with advanced state separation, Lunul provides developers and institutions with an uncompromised execution environment.

Core Protocol Spec

Lunul achieves sub-second block confirmation times while maintaining absolute security guarantees through its validated asynchronous state machine replication protocol.

Protocol Architecture

Unlike legacy monolithic chains where computation and data storage are tightly coupled inside smart contracts, Lunul's architecture separates execution logic from persistent state storage.

Stateless Programs

Programs (smart contracts) contain executable bytecode only. All runtime data is stored in isolated, program-owned accounts, unlocking massive parallel transaction execution.

Deterministic Account Model

Every account explicitly declares its read/write dependencies upfront in transaction headers, allowing the runtime scheduler to optimize CPU core allocation.

Proof-of-State Consensus

Lunul utilizes an optimized BFT (Byzantine Fault Tolerant) consensus engine paired with cryptographic verifiable delay functions (VDFs) to order transactions without inter-node chatter latency.

Lunul SDK Quickstart

Interact with the Lunul network programmatically using the official TypeScript client library.

client_transfer.ts TypeScript 
import { LunulClient, clusterApiUrl, LAMPORTS_PER_LUN } from '@lunul/web3.js';

// Initialize connection to Lunul Mainnet-Beta
const client = new LunulClient(clusterApiUrl('mainnet-beta'));

async function executeTransfer(senderWallet, recipientKey) {
  const transferAmount = LAMPORTS_PER_LUN / 10n; // 0.1 LUN
  
  const txSignature = await client.transferSOL({
    sender: senderWallet,
    recipient: recipientKey,
    lamports: transferAmount
  });

  console.log(`Transaction confirmed with signature: ${txSignature}`);
}
